## 二、平台闭环能力

v1.0 已形成完整企业 AI 中台闭环：

1. **AI Gateway** — 统一模型接入（冻结，业务侧不得直改）
2. **Knowledge Platform** — 企业知识底座
3. **Enterprise RAG Engine** — 检索增强问答
4. **Agent Center** — 企业 AI 员工
5. **MCP & Tool Calling** — 统一工具与 MCP 网关
6. **Workflow Engine** — 企业工作流引擎
7. **Business Integration Platform** — 业务系统统一接入

---

## 三、企业架构（冻结）

```
Business
↓
Workflow Engine
↓
Agent Center
↓
Tool Manager
↓
MCP Gateway
↓
Business Connector
↓
Business System
```

约束（v1.0 起长期有效）：

- 业务系统必须经 Workflow 管控
- 禁止绕过 Agent / Tool / MCP 层
- 资金类与配置类写操作必须走审批 Workflow
- AI Gateway 内部实现保持稳定，不因业务接入而重构

## 四、封版说明

平台层已达到企业级基础架构目标，可作为后续 ZRH 系列产品的统一 AI 中台：

- ZRHPay
- ZRH Router OS
- ZRH Accounting System
- Document Center / Knowledge Platform

**后续重点不再扩展平台骨架**，转向：真实业务接入、审批能力、生产治理、企业安全与部署运维。
